# AI Smoke and Fire Detection Application

## Overview

This application integrates two AI models
for smoke detection and fire classification.

## Features

- Smoke detection with bounding boxes.
- Fire classification probabilities.
- Estimated wildfire danger level.
- Real-time FPS monitoring.

## AI Models

- [Smoke Detection Model](https://www.kaggle.com/code/rubcost/notebookyolov26-aug)
- [Fire Classification Model](https://www.kaggle.com/code/rubcost/notebooka7da5cebb6)
