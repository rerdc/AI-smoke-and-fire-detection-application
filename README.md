# AI Smoke and Fire Detection Application

This application integrates two previously trained AI models, one for smoke detection and another for fire classification, with the goal of estimating the severity of forest wildfires.

The application processes a video source through both models and displays the following information:

- **Smoke Detection:** Bounding boxes highlighting detected smoke regions.
- **Inference Probabilities:** The prediction probabilities generated by both AI models.
- **Wildfire Danger Level:** An estimated danger level determined by combining the two model probabilities and applying predefined threshold values.
- **FPS:** The number of frames processed per second, providing an indication of the application's execution performance.

## AI Models
